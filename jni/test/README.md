rialcpp dynamically loads `rial.jar` file while constructing JVM.

to open `rial.jar`, we install rial.jar to `PREFIX/share/rialcpp` and our code
assumes that `rial.jar` is always there.

to test the library, we need to install rialcpp and use it.

this directory contains independent CMake project that uses rialcpp.
Use this as an example repo to use rialcpp from your app.
